# Multi-Hop Threat Propagation Explorer

## Overview
Models the contagion trajectory of fraud threats across graph relationships from an origin entity.

## Features
* **Bounded Contagion Modeling**: Explores 1 to 5 graph hops.
* **Chronological Progression**: Step-by-step timeline ($T_0 	o T_3$) with financial exposure deltas.
* **Interactive Topologies**: D3-ready graph visualizer with risk-weighted node and link styling.
* **Automated Containment Suggestions**: Targeted administrative holds and counterparty quarantines.

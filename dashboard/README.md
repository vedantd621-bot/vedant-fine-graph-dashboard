# FinGraph Analyst Investigation Dashboard

An interactive React + TypeScript application featuring D3 force-directed transaction graphs, real-time KPI metrics, entity search, community syndicate views, money-trail path exploration, and simulated syndicate freeze action triggers.

## Key Views & Features
1. **Network View**: Force-directed multi-entity graph with risk color coding (Low = Green, Medium = Yellow, High = Orange, Critical = Red).
2. **Investigation Panel**: Detailed node inspect view with PageRank, Louvain Community, incoming/outgoing transactions, and explainable risk breakdown.
3. **Money Trail Tracer**: Path highlighting from origin through mules to beneficiaries.
4. **Simulated Freeze Syndicate**: Immediate demonstration action marking accounts frozen and logging immutable audit entries.

## Quickstart
```bash
npm install
npm start
```
